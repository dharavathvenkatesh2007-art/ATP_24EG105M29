#  Week-4: HTML Practice

This folder contains the **Week-4 assignments** for the ATP_24EG105M29 course.  
It focuses on **HTML basics** such as lists, tables, and simple page structures.

---

##  Folder Structure & Explanation

### 1. `3pochiaCat/`
- **Purpose**: Practice exercise related to HTML structure and content formatting.
- **Contents**:
  - HTML file(s) demonstrating headings, paragraphs, and possibly images.
- **Concepts**:
  - Basic HTML tags.
  - Page layout.
- **Learning Outcome**: Learn how to **structure simple web pages**.

---

### 2. `4tables/`
- **Purpose**: Demonstrates HTML table creation.
- **Contents**:
  - HTML file(s) with table examples.
- **Concepts**:
  - `<table>`, `<tr>`, `<td>`, `<th>` tags.
  - Table styling and alignment.
- **Learning Outcome**: Practice **tabular data representation**.

---

### 3. `fruits-vegitables.html`
- **Purpose**: HTML page listing fruits and vegetables.
- **Concepts**:
  - Ordered and unordered lists.
  - Semantic HTML.
- **Learning Outcome**: Learn how to **organize content with lists**.

---

### 4. `unorderd.html`
- **Purpose**: Demonstrates unordered lists in HTML.
- **Concepts**:
  - `<ul>` and `<li>` tags.
- **Learning Outcome**: Practice **list creation**.

---
