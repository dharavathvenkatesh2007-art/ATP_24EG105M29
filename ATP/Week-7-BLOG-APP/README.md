# Week 7 - Blog App

This folder contains the complete, full-stack Blog Application.

## File Information

- **`Frontend` (directory)**: The client side of the blog application, built using React. Handles the UI, routing, and interactions.
- **`Backend` (directory)**: The server side of the blog application, built using Node.js and Express. Provides the API endpoints for creating, reading, updating, and deleting blog posts.
