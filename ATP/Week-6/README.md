# 📘 Week-6 Repository Overview

This repository contains the **Week-6 assignments and projects** for the ATP_24EG105M29 course.  
It includes multiple subfolders focusing on **React.js concepts, Context API, dynamic table creation, and a mini-project**.

---

##  Folder Structure & Explanations

### 1. ContextApiSync
- **Purpose**: Demonstrates how to use **React Context API** for synchronizing state across components.
- **Contents**:
  - `App.js` → Root component where context is created and provided.
  - `Context.js` → Defines the context object and provider.
  - Child components consuming context values.
- **Key Concepts**:
  - Avoiding **prop drilling** by sharing data globally.
  - Using `useContext` hook for easy access.
- **Learning Outcome**: Master **global state management** in React.

---

### 2. Create_Table_Dinamically
- **Purpose**: Shows how to **generate tables dynamically** based on user input or fetched data.
- **Contents**:
  - Scripts to create rows and columns programmatically.
  - Examples of rendering tables from arrays/objects.
- **Key Concepts**:
  - Conditional rendering in React.
  - Mapping data structures to UI elements.
- **Learning Outcome**: Learn how to **render dynamic UI components** and handle structured data.

---

### 3. Miniproject
- **Purpose**: A small-scale project integrating Week-6 concepts into a working application.
- **Contents**:
  - Complete React app with multiple components.
  - Demonstrates CRUD operations, state management, and UI rendering.
- **Key Concepts**:
  - Combining Context API, dynamic rendering, and component-based design.
  - Practical application of theoretical knowledge.
- **Learning Outcome**: Apply concepts in a **real-world mini-project**.

---

### 4. React-Frontend
- **Purpose**: A frontend application built with **React.js**.
- **Contents**:
  - React components for forms, tables, and navigation.
  - Hooks (`useState`, `useEffect`) for managing state and side effects.
  - Routing setup for navigation between pages.
- **Key Concepts**:
  - Component-based architecture.
  - Handling user input and rendering outputs.
- **Learning Outcome**: Gain confidence in **building user interfaces** with React.
