# Week 5

This folder contains a mix of advanced HTML/CSS styling concepts and an introduction to React.

## File Information

- **`5simpletable` (directory)**: Examples of structuring simple HTML tables.
- **`6Table-externalcss` (directory)**: Examples showing how to apply external CSS styles to HTML tables.
- **`7Parent-child` (directory)**: Demonstrations of parent-child relationships in HTML/CSS and how to style nested elements.
- **`8Div-tag` (directory)**: Demonstrations focusing heavily on the usage and styling of the `<div>` tag for layout.
- **`9Cityweb` (directory)**: A mini project or layout related to a city-themed webpage.
- **`Product-React` (directory)**: An introductory React project focusing on product listings.
- **`REACT-P` (directory)**: General initial React examples and playground.
- **`User-React` (directory)**: An introductory React project focusing on user data handling.
