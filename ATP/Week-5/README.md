#  Week-5: HTML, CSS & React Practice

This folder contains the **Week-6 assignments** for the ATP_24EG105M29 course.  
It includes exercises in HTML/CSS (tables, divs, parent-child structure) and introductory React projects.

---

##  Folder Structure & Explanation

### 1. `5simpletable/`
- **Purpose**: Demonstrates basic HTML table creation.
- **Concepts**:
  - `<table>`, `<tr>`, `<td>`, `<th>` tags.
- **Learning Outcome**: Learn how to **represent tabular data**.

---

### 2. `6Table-externalcss/`
- **Purpose**: Shows how to style tables using external CSS.
- **Concepts**:
  - Linking CSS with `<link>` tag.
  - Table styling (borders, colors, spacing).
- **Learning Outcome**: Practice **separating structure and style**.

---

### 3. `7Parent-child/`
- **Purpose**: Demonstrates parent-child relationships in HTML.
- **Concepts**:
  - Nested elements.
  - CSS selectors for parent-child.
- **Learning Outcome**: Understand **hierarchical HTML structure**.

---

### 4. `8Div-tag/`
- **Purpose**: Practice using `<div>` for layout.
- **Concepts**:
  - Block-level elements.
  - Grouping content.
- **Learning Outcome**: Learn **page structuring with divs**.

---

### 5. `9Cityweb/`
- **Purpose**: A small web project about cities.
- **Concepts**:
  - Combining HTML, CSS, and possibly JS.
- **Learning Outcome**: Apply **web page design skills** in a mini-project.

---

### 6. `Product-React/`
- **Purpose**: React project for product listing.
- **Concepts**:
  - React components.
  - Props and state.
- **Learning Outcome**: Build a **dynamic product UI** with React.

---

### 7. `REACT-P/`
- **Purpose**: Another React practice project.
- **Concepts**:
  - Component-based architecture.
  - JSX syntax.
- **Learning Outcome**: Reinforce **React fundamentals**.

---

### 8. `User-React/`
- **Purpose**: React project for user management/display.
- **Concepts**:
  - Handling user data with props/state.
  - Rendering lists dynamically.
- **Learning Outcome**: Practice **React data-driven components**.
