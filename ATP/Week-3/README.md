#  Week-3: Backend Practice

This folder contains the **Week-3 assignments** for the ATP_24EG105M29 course.  
It focuses on **backend development basics** using Node.js/Express, organized into two separate projects.

---

##  Folder Structure & Explanation

### 1. `backend-1/`
- **Purpose**: Introductory backend project.
- **Contents**:
  - `server.js` → Entry point of the application, sets up Express server.
  - `routes/` → Defines API endpoints.
  - `controllers/` → Contains logic for handling requests.
  - `package.json` → Project configuration and dependencies.
- **Concepts**:
  - Setting up a Node.js server.
  - Basic routing with Express.
- **Learning Outcome**: Learn how to **create and run a simple backend server**.

---

### 2. `backend-2/`
- **Purpose**: Extended backend project with more features.
- **Contents**:
  - `server.js` → Main server file with middleware and routes.
  - `routes/` → Additional or advanced API endpoints.
  - `controllers/` → Business logic for CRUD operations.
  - `models/` → Data models (if using MongoDB or similar).
  - `package.json` → Dependencies and scripts.
- **Concepts**:
  - Middleware usage.
  - Handling multiple routes and controllers.
  - Possibly database integration.
- **Learning Outcome**: Practice **structuring a backend application** with modular code.
