# JavaScript Assignments – Week 2

This repository contains various JavaScript assignments and exercises designed to practice **array methods, object manipulation, asynchronous operations, and class-based programming**. Each file demonstrates a specific concept with test data and console outputs.

---

##  File Overview
- **shopping_cart_summary.js**  
  Implements a shopping cart summary using:
  - `filter()` → in-stock products  
  - `map()` → `{ name, totalPrice }`  
  - `reduce()` → grand total value  
  - `find()` → details of "Mouse"  
  - `findIndex()` → position of "Keyboard"

- **Student_Performance_Dashboard.js**  
  College result analysis system:
  - `filter()` → passed students  
  - `map()` → grade assignment (A–D)  
  - `reduce()` → average marks  
  - `find()` → student with 92 marks  
  - `findIndex()` → student "Kiran"

- **temperatures-operations.js**  
  Temperature dataset operations:
  - `filter()` → above 35°C  
  - `map()` → Celsius → Fahrenheit  
  - `reduce()` → average temperature  
  - `find()` → first above 40°C  
  - `findIndex()` → temperature 28°C

- **Bank_Transaction_Analyzer.js**  
  Bank statement summary:
  - `filter()` → credit transactions  
  - `map()` → transaction amounts  
  - `reduce()` → final balance  
  - `find()` → first debit transaction  
  - `findIndex()` → transaction with amount 10000

- **course_list_for_display.js**  
  Course list formatting:
  - `filter()` → names length > 5  
  - `map()` → uppercase names  
  - `reduce()` → single string `"COURSE | COURSE | ..."`  
  - `find()` → course "react"  
  - `findIndex()` → course "node"

- **Employee_Payroll_Processor.js**  
  Salary processing module:
  - `filter()` → IT department employees  
  - `map()` → add 10% bonus  
  - `reduce()` → total salary payout  
  - `find()` → employee with salary 30000  
  - `findIndex()` → employee "Neha"

- **marks_from_exam_system.js**  
  Exam marks analysis:
  - `filter()` → pass marks ≥ 40  
  - `map()` → add 5 grace marks  
  - `reduce()` → highest mark  
  - `find()` → first mark below 40  
  - `findIndex()` → mark 92

- **Movie_Streaming_Platform.js**  
  Movie recommendation system:
  - `filter()` → Sci-Fi movies  
  - `map()` → formatted title + rating  
  - `reduce()` → average rating  
  - `find()` → movie "Joker"  
  - `findIndex()` → movie "Avengers"

- **Update_User_Object.js**  
  Demonstrates object cloning with spread operator and adding new property (`age`).

- **Copy_Extend_Arrayexercise1day4.js**  
  Array copying with spread operator, extending with `"orange"`.

- **Shallow_Copy.js**  
  Shallow copy of an object using spread operator. Shows mutation effects on nested objects.

- **Deep_Copy.js**  
  Deep copy using `structuredClone()`. Demonstrates isolation of nested properties.

- **3Otpday4.js**  
  OTP countdown simulator:
  - Sends OTP  
  - 10-second countdown  
  - Resend enabled after countdown

- **Examday4.js**  
  Exam portal simulator:
  - Immediate submission message  
  - Delayed evaluation (2s)  
  - Result after 4s

- **librarybookday4.js**  
  Library Book Management System:
  - `Book` class with properties & methods (`borrow`, `returnBook`, `getInfo`, `isLongBook`)  
  - Operations: borrow/return, count long books, list available books
