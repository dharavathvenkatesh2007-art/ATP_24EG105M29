# Week 1

This folder contains introductory JavaScript files covering basic operations and algorithms.

## File Information

- **`1BigOf2num.js`**: Logic to find the largest among two numbers.
- **`2BigOf3num.js`**: Logic to find the largest among three numbers.
- **`3SumofArray.js`**: Calculates the total sum of elements in a given array.
- **`4minmarks.js`**: Finds the minimum value in an array of marks.
- **`5BigFun.js`**: A function that receives 3 numbers and returns the largest number.
- **`6SumFun.js`**: A function that receives an array as an argument and returns the sum of its elements.
- **`7SearchFun.js`**: A function that searches for an element in an array and returns its index, or "not found".
- **`objectoperationday2.js`**: Introduction to JavaScript objects, including array operations like inserting, deleting, and modifying object properties.
