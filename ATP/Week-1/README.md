#  Week-1: JavaScript Basics & Problem Solving

This folder contains the **Week-1 assignments** for the ATP_24EG105M29 course.  
It focuses on **fundamental JavaScript programming** — operators, conditions, loops, and small problem-solving exercises.

---

##  Files & Explanations

### 1. `1big number.js`
- **Purpose**: Finds the largest number among two given numbers.
- **Concepts**:
  - Comparison operators (`>`, `<`).
  - Conditional statements (`if-else`).
- **Learning Outcome**: Practice **basic decision-making** in JS.

---

### 2. `2.greatestof3number.js`
- **Purpose**: Determines the greatest number among three inputs.
- **Concepts**:
  - Nested `if-else` conditions.
  - Logical operators.
- **Learning Outcome**: Learn how to handle **multiple comparisons**.

---

### 3. `3sumofgivennumber.js`
- **Purpose**: Calculates the sum of digits of a given number.
- **Concepts**:
  - Loops (`while`).
  - Modulus operator (`%`) for extracting digits.
- **Learning Outcome**: Understand **digit manipulation** and iteration.

---

### 4. `4.smallest.js`
- **Purpose**: Finds the smallest number among given inputs.
- **Concepts**:
  - Conditional branching.
  - Comparison operators.
- **Learning Outcome**: Reinforce **minimum value logic**.

---

### 5. `5.js`
- **Purpose**: Likely a simple program (e.g., factorial, prime check, or arithmetic task).
- **Concepts**:
  - Variables and loops.
  - Basic problem-solving.
- **Learning Outcome**: Apply **operators and loops** in a small exercise.

---

### 6. `6.js`
- **Purpose**: Another practice program (e.g., palindrome check or Fibonacci series).

---

### 7. `7.js`
- **Purpose**: Small exercise (e.g., Armstrong number or reverse number).

### 8. `emp.js`
- **Purpose**: Displays employee details or performs operations on employee data.
